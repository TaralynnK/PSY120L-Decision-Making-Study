# PSY120L-Decision-Making-Study

Decision-Making Study

This repository includes the published HTML version of Taralynn's PSY 120L final reproducible report for Developmental 2's Decision-Making Study. 
This project sought to identify whether perceived peer norms, moderated by conscientiousness, influence levels of risky decision-making and peer norm resistance in undergraduate UC Santa Barbara students. 

This report was produced using R/RStudio and Quarto, and is published as index.html.

The dataset is not included in this repository.
